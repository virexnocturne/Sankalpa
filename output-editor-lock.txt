POMODORO BEHAVIOR FINDINGS
- "Save" vs "Start Pomodoro Lock Now": When the Pomodoro radio option is selected, clicking "Save" computes `StartTimedLockMinutes = (focus * cycles) + (pbreak * (cycles - 1))` and saves all profile changes, which signals MainViewModel to activate the timed session immediately. The dedicated "Start Pomodoro Lock Now" button inside the Pomodoro panel performs the exact same minute calculation and invokes `SaveButton_Click`, providing an intuitive in-panel start trigger for users. The behavior is consistent, though having two buttons that both start the session immediately could be streamlined in a future behavioral pass.

- 80 characters (Block profile lock): Created as an intentionally high-friction deterrent for unlocking blocked distraction profiles via an 80-character random alphanumeric string.
- 64 characters (DNS lock): Generated as a 64-character hex hash directly from the background service for tamper protection. Both numbers are intentional and match their respective underlying security designs.
