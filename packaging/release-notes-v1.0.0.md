## Sankalpa v1.0.0 — Distraction-Free Focus & Productivity Suite

We are excited to announce the initial public release of **Sankalpa**, a tamper-resistant focus, website, and application blocker for Windows.

### ✨ Features
- **Windows Desktop Dashboard (`Sankalpa.exe`)**: Modern WPF UI featuring Black, Grey, and White themes with 6 accent colors (Emerald, Indigo, Violet, Amber, Rose, Slate).
- **Tamper-Resistant Windows Service (`Blocker.Service.exe`)**: Background watchdog running as SYSTEM to manage local DNS/hosts redirection, process monitoring, and strict lock schedules.
- **Companion Browser Extension**: Offline Manifest V3 extension for Chrome, Edge, Brave, and Firefox for seamless, zero-latency website blocking.
- **1-Click Windows Setup (`Sankalpa-Setup-1.0.0.exe`)**: Automatically configures the service, autostart, and native messaging bridge without manual batch scripts.
- **Privacy-First**: 100% offline, on-device data processing. No tracking, telemetry, or cloud accounts.

### 📦 Downloads & Installation
1. Download **`Sankalpa-Setup-1.0.0.exe`** below.
2. Run the installer (requires Administrator elevation once to register the background service).
3. To enable browser blocking, install the extension from the Chrome Web Store or load **`sankalpa-extension-v1.0.0.zip`**.
