Core Capabilities

Built for moments when willpower is not enough

Configure context-specific profiles for websites, installed desktop applications, automated schedules, lock barriers, and fullscreen meditation sessions.

Multi-Target Website & Application Blocklists

Combine domain rules, URL paths, wildcard subdomains, and executable blacklists inside reusable profiles like Deep Work or Study.

  • Block All + Exceptions: Flip into strict whitelist mode and permit only specific reference paths or login endpoints.
  • System-Wide Hosts Enforcement: Blocks root domains across every desktop process and non-browser app, not just browsers with extensions.
  • Instant Process Termination: Scans running and installed Windows apps, terminating games, chat clients, or distracting binaries immediately on launch.
  • Live URL Rule Tester & Bulk Import: Verify any rule or import .txt domain lists directly inside the editor.

Automated Schedules, Allowances & Pomodoro Cycles

Lock in your weekly cadence so enforcement starts right on time without relying on manual discipline.

  • Multi-Day Recurring Windows: Stack weekday work blocks and weekend study intervals per profile.
  • Daily Usage Allowance: Budget a daily recreation quota (15m, 30m, 45m, 60m) before the profile locks down for the rest of the day.
  • Pomodoro Focus Sprints: Run structured work/break cycles with earned break reward credits upon completion.

Five Graduated Lock Protections

Stop impulse overrides before they happen. Once a lock engages, neither settings edits nor early toggle switches can disable the profile until the barrier is cleared.

  • Complete Timed Lock: Unconditional lock from 1 hour up to 1 year—cannot be stopped or edited early.
  • Schedule Lock: Automatically pins the toggle switch disabled for the full duration of configured schedule windows.
  • Delayed Unlock: Requires waiting out an active 15m, 30m, 1h, or 2h countdown timer to defeat impulsive unlocking.
  • Random 80-Char Challenge & Password Lock: Choose zero-typo random text entry or PBKDF2/SHA-256 salted password verification.

Meditation & Computer Lockdown Mode

Enter a calm, multi-monitor fullscreen Zen Shield that suspends background distractions while giving safe, path-pinned access to only the applications you whitelist.

  • Hardened Zen Shield & Mini-HUD: Suppresses Alt+Tab, Win+Tab, and Task View gestures while keeping a compact floating Mini-HUD over whitelisted apps.
  • Offline Ambient Soundscapes: Seamless 16-bit PCM loops (Rain, Library, Forest, Singing Bowls) plus local audio & M3U/M3U8 playlist import.
  • Obsidian-Style Notes & Zen Snipper: Slide-out Markdown reflection drawer with interactive checkboxes, Ctrl+Shift+S screen snips, and 3-way Markdown export.
  • v1.3.6 Zen UI & CLI Meditation: Discrete 5-event WinEvent filter coalescing, async single-verify PBKDF2 unlock, full CLI lockdown controls, and secure M3U playlist import.

Strict UninstallGuard

sankalpa-cli check-uninstall audits both the live service and offline SQLite/hosts files. Windows Settings and unins000.exe refuse removal while locks or schedules remain active.

Path-Pinned Immunity

SystemHelperGuard canonicalizes OS binary paths to defeat %TEMP% spoofing and prevents CLI tools from inheriting GUI app allowances during Zen lockdown.

Reboot-Immune Timers

Monotonic deadlines and PBKDF2/SHA-256 lock secrets persist in local SQLite. Clock skew or system reboots never reset active sessions.

Browser Guard

Secondary browsers lacking the extension or Incognito windows without permission face a 60-second grace toast before automatic process termination.

Automation & Scripting

Full headless control with sankalpa-cli.exe

Trigger blocks, run meditation sessions, capture reflection notes, manage delayed unlocks, and inspect security audit trails directly from PowerShell or scheduled scripts.

Available in install directory
sankalpa-cli status Inspect active focus sessions, service status, and enforcement state.
sankalpa-cli start --profile "Deep Work" --duration 45m Launch an immediate block session for an existing profile.
sankalpa-cli meditation start --duration 20m --apps "spotify.exe,notion.exe" --sound rain Start fullscreen Zen Lockdown with whitelisted apps and offline Rain audio.
sankalpa-cli meditation note --text "Quick thought captured" Append a reflection note directly into the local Notes vault.
sankalpa-cli meditation schedule add --time 15:00 --days Mon,Tue,Wed,Thu,Fri --duration 20m Automate a recurring weekday afternoon meditation lockdown.
sankalpa-cli delayed-unlock request --name "Deep Work" Initiate a delayed unlock countdown and print the cancellation token.
sankalpa-cli lock-dns --mode Timer --duration 86400 Lock OS-level filtered DNS settings for 24 hours.
sankalpa-cli events --limit 10 Audit recent blocked processes, domain redirects, and protection events.

Step 1: Run the Windows Setup Wizard
  1. Download and launch Sankalpa-Setup-1.3.6.exe.
  2. Approve the single User Account Control (UAC) prompt so setup can register the tamper-resistant SankalpaService under LocalSystem.
  3. If Windows Defender SmartScreen displays a prompt on a fresh release, select More info → Run anyway after checking the SHA-256 digest above.
Step 2: Load the Companion Browser Extension
  1. Open chrome://extensions (Chrome/Brave/Opera), edge://extensions (Edge), or about:debugging (Firefox) and enable Developer mode.
  2. Extract sankalpa-extension-v1.3.6.zip and select Load unpacked (or click Open folder in Sankalpa's status bar).
  3. Open extension details and enable Allow in Incognito / InPrivate so browser-level blocking remains active in private windows.
Step 3: Build & Test from Source (.NET 8 SDK)

Requires Windows 10/11 (x64), .NET 8.0 SDK, and Inno Setup 6+ for installer packaging.

git clone https://github.com/virexnocturne/Sankalpa.git
cd Sankalpa
dotnet test Blocker.sln
dotnet build Blocker.sln -c Release
Privacy Guarantee

Your focus habits stay on your machine

Sankalpa operates with zero remote infrastructure. Every rule, countdown, note, and event stays locally inside %LocalAppData%\Sankalpa\data\.

100% Offline & Local

Zero analytics SDKs, zero tracking cookies, and zero outbound requests from either the Windows binaries or the companion browser extension.

No Accounts or Paywalls

No email sign-up, cloud dashboard, or recurring subscription gates your block profiles, schedules, or lock protections.
