Privacy Policy for Sankalpa & Sankalpa Blocker Companion

Sankalpa is engineered as a privacy-first, offline-only focus and blocking tool. Neither the Windows desktop suite nor the companion browser extension transmits browsing history, blocklists, or telemetry to any remote server.

1. Core Principle: 100% Local & Offline

  • No Remote Servers: Sankalpa operates no external cloud servers or remote databases storing your information.
  • No Analytics or Telemetry: Contains zero tracking cookies, analytics SDKs, advertising beacons, or usage telemetry.
  • No Data Selling: We never sell, rent, monetize, or transfer user data to any third party under any circumstances.

2. Information Handled Locally on Your Device

A. Sankalpa Desktop Application (Windows)

  • Block Profiles & Rules: Custom domains, application executable names, schedules, and lock configurations are stored exclusively in %LocalAppData%\Sankalpa\data\.
  • Session History & Notes: Meditation histories, reflection notes, and event logs remain inside your local SQLite database and JSON storage on your machine.
  • System Permissions: Elevated LocalSystem privileges are used strictly to update the local Windows hosts file, manage DNS shielding, and enforce local process blocking.

B. Sankalpa Blocker Browser Companion Extension

  • On-Device URL Evaluation: Destination hostnames are checked locally against your active block profiles before navigation completes.
  • No History Logging: Non-matching URLs are discarded immediately. Browsing history is never logged or transmitted externally.
  • Native Inter-Process Communication: Communicates exclusively with local Blocker.NativeHost.exe via standard OS pipes (nativeMessaging).

3. Browser Extension Permission Justifications

Manifest V3 Permissions Used Exclusively Offline
Permission Local Purpose
nativeMessaging Communicates locally with Blocker.NativeHost.exe via standard I/O pipes to synchronize active profiles and session countdowns.
webNavigation Intercepts navigations before blocked pages load and redirects immediately to the local hold screen.
tabs Reads active tab hostnames locally to match against active block rules and support 1-click popup blocking.
storage Caches active profile rules and timer state locally inside the browser across restarts.
alarms Runs periodic local heartbeats to verify connection health with the desktop service.
<all_urls> Evaluates user-configured domain rules across arbitrary websites completely on device.

4. Data Retention, Children's Privacy & Contact

  • Local Data Control: All desktop data lives under %LocalAppData%\Sankalpa\. Uninstalling Sankalpa or removing the browser extension deletes locally cached rules and state.
  • Children's Privacy: Sankalpa collects no personal information from any user, including children under 13.
  • Questions or Feedback: Open an issue on our public repository at github.com/virexnocturne/Sankalpa.
